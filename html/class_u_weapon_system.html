Detailed Description

All global functionality for the UWeaponSystem, comparable to the UItemSystem. Unlikely the UItemSystem, most of the UWeaponSystem's struct accessing can just be done directly. That's because this system is generally only used by a few classes.. If we change a member variable, it's just 5-10 minutes of a couple files to change everything else to match. These are for more in depth inconvenient things like calling data rows from data tables and validating weapon data.
