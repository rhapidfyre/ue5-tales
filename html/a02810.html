int UInventorySlot::AddItem ( const FName & ItemName,

Adds a brand new item by the FName given, if the slot is empty or if the slot contains the same item with the same generated statics. Generates a result from all possible outcomes of the item. To control exactly what is created, either copy an item using 'CopyItemFromSlot', or use the overload function 'AddItem(FItemStatics, int)'
