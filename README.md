# Tales of the Dungeoneer
A dungeon crawling RPG game by Take Five Games, LLC.

# Description
Tales of the Dungeoneer allows players to take on one of many roles and explore, fight, craft, collect and overcome obstacles in procedurally generated dungeons. Players beware, the optional Dungeon Guide position can modify the dungeon, make traps easier or harder and change the course of your play as you try to fight your way to the finish!
